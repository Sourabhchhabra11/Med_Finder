Overview

What is MedFinder?

MedFinder is a web application that helps patients instantly find which nearby verified medical stores have a specific medicine in stock — showing real-time availability, price, and distance, so no one has to roam from pharmacy to pharmacy during an urgent medical need.

Instant Search

Find which nearby recognized medical stores have a specific medicine in stock.

Real-Time Data

See live availability, price, and distance across all listed stores.

Reserve Feature

Hold the medicine at a chosen store until you arrive to pick it up.

Verified Stores

Pharmacy registration ensures only recognized and authentic stores are listed.

System Design

How It Works

MedFinder's core system is modeled around 5 processes — from authentication and store registration to the actual search and reservation flow.

1
Modeled

Manage Authentication

Handles login and registration for both patients and store staff.

2
Modeled

Manage Store Registration

Store staff submit pharmacy details, which are verified by an Admin before going live.

3
Modeled

Manage Inventory

Store staff add, update, or remove medicine stock entries in real time.

4
Modeled

Search Medicine

Parses a patient's query, matches it against the medicine catalog, checks live stock, and ranks results by distance and price.

5
Modeled

Manage Reservation

Validates availability, creates a reservation record, holds stock, and notifies the store.
