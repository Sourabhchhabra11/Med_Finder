Overview

What is MedFinder?

A web application that helps patients instantly find which nearby verified medical stores have a specific medicine in stock — showing real-time availability, price, and distance, so no one has to roam from pharmacy to pharmacy during an urgent medical need.

Instant Search

Find which nearby recognized pharmacies have a specific medicine in stock, in seconds.

Live Data

See real availability, price, and distance for every matching pharmacy, ranked nearest first.

Verified Stores

Every listing traces to a recognized pharmacy — nothing unmoderated shows up in results.

Reserve Ahead

Hold an item at the pharmacy of your choice so it's waiting when you arrive.

System Design

How it works

MedFinder's core system is modeled around five processes — from authentication and store registration to the actual search and reservation flow.

1

Manage Authentication

Handles login and registration for both patients and store staff.

2

Manage Store Registration

Store staff submit pharmacy details, verified before going live — keeping listings trustworthy.

3

Manage Inventory

Store staff add, update, or remove medicine stock entries in real time.

4

Search Medicine

Matches a patient's query against the catalog, checks live stock, and ranks results by distance and price.

5

Manage Reservation

Validates availability, holds stock, and notifies the store — with support for cancellation.
